استخدمه عندماUSE WHEN
  • تعرف المفتاح مسبقاً.
  • تريد زمناً شديد الانخفاض.
  • لا تحتاج JOIN أو بحثاً داخل القيمة.
  • بياناتك JSON أو كائناً كاملاً.
  • الحقول تتغير بسرعة.
  • تحتاج فهارس واستعلام حقول.
  • الكتابات بالآلاف أو الملايين.
  • الاستعلامات معروفة مسبقاً.
  • تحتاج توسعاً أفقياً ضخماً.
  • العلاقات مهمة مثل البيانات.
  • السؤال يعبر عدة مستويات.
  • JOIN أصبحت كثيرة ومرهقة.
لا تستخدمه عندماAVOID WHEN
  • تبحث داخل قيمة معقدة.
  • العلاقات أساسية.
  • معاملات متعددة السجلات ضرورية.
  • JOIN وmany-to-many تهيمن.
  • المخطط الصارم شرط أساسي.
  • تقارير SQL التقليدية هي الحمل الأساسي.
  • البيانات صغيرة وتناسب خادماً واحداً.
  • تحتاج استعلامات حرة وJOIN.
  • تحتاج ACID واسعاً بين الجداول.
  • العلاقات قليلة وسطحية.
  • البيانات Time-series ضخمة.
  • البحث النصي الكامل هو الهدف.
