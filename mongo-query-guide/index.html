EXAM SENTENCE

Display products with a price greater than 50.

  1. productsالكلمة بعد products تصبح اسم الـCollection.
  2. priceالحقل الذي نطبّق عليه الشرط.
  3. greater thanتعني العامل $gt.
  4. 50القيمة رقم؛ لذلك لا نضعها بين علامتي اقتباس.
FINAL QUERY db.products.find({ price: { $gt: 50 } })
02 · CHOOSE THE OPERATOR

حوّل كلمات السؤال إلى رموز

هذه أهم الكلمات التي تحتاجها لصياغة أسئلة المقارنة المشابهة للنموذج.

QUESTION WORDS OPERATOR المعنى EXAMPLE
greater than$gtأكبر منprice: { $gt: 50 }
at least / ≥$gteأكبر من أو يساويage: { $gte: 18 }
less than$ltأصغر منstock: { $lt: 10 }
at most / ≤$lteأصغر من أو يساويprice: { $lte: 200 }
equal tofield: valueيساويstatus: "active"
not equal$neلا يساويstatus: { $ne: "blocked" }

داخل المحاضرة: المثال الصريح يستخدم $gt مع find() وsort(). بقية العوامل امتداد مباشر لنفس قاعدة المقارنة وتفيدك في تغيير صيغة السؤال.
